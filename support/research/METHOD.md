# How the 48 ligand pairs were selected

The current experiment is a **single fixed screen**, not an active-learning loop. It uses the previously selected 48 distinct pairs from 30 available ligands: **24 retained Claude/diversity consensus choices and 24 Sobol exploration choices**. Every ligand occurs at least once, with frequencies 1–8. L07 is unavailable and excluded. No pair-yield data were used to choose this screen.

Claude scored ligand cooperativity using ligand IDs, names and SMILES, the substrate/product identities and 17 reported single-ligand yields for the same substrate from [the original study's SI, Table S2, page S35](https://doi.org/10.1039/D5SC00912J). Unreported ligand yields remained null. Each pair received five accepted scores in small anchor/partner requests, with prompt caching; the mean score ranked promise. Scores were not calibrated yield predictions. The historical prompt and provider usage records are preserved in [the scoring evidence](../campaigns/hackathon2026/scoring/).

Initialization also used frozen, order-symmetric T5-base embeddings of ligand pairs. The preliminary consensus gave equal weight to Claude rank and structural diversity. David Ming Segura's adopted implementation retained a diverse 24-pair subset with all-ligand coverage, then matched 24 Sobol targets to distinct remaining pairs. The sampling representation was standardized, reduced to 16 PCA components and scaled to [0,1]. It uses language-model representations without manual ligand parameterization; no GoLLuM optimizer or pair-yield surrogate was trained.

The [selection trace](../campaigns/hackathon2026/round1_design.csv.selection.csv), [coverage counts](../campaigns/hackathon2026/round1_design.csv.ligand_coverage.csv), [initialization statistics](initialization-review.md), cached embeddings and implementation under `code/` preserve the initialization. David's [original notebook](https://github.com/MiquelAngelPerezPuigdo/Agentic-AI-for-Dual-Ligand-Discovery/blob/c2682f3db09eb496b92d11fb6725e9870157e301/notebook/batch_suggestions.ipynb) remains available at its contributor commit. The full previous two-round implementation can be inspected at [commit dba4824](https://github.com/MiquelAngelPerezPuigdo/Agentic-AI-for-Dual-Ligand-Discovery/tree/dba4824); it is not the active run procedure.

The [original paid scoring request](../campaigns/hackathon2026/scoring/example_request.json) specified **250 µL and mesitylene** as the internal standard. The current bench run uses **100 µL and naphthalene**, with the same 0.1 M substrate concentration, ligand/Pd molar loadings, 95 °C and nominal four-hour reaction time. The pair selection was retained without a new scoring campaign; the saved scores were not regenerated for those later changes.

The readable `claude-scoring-prompt.txt` and preserved scoring code are a **later format-7 preview**, with naphthalene and clarified partner-ID wording. They are not the exact requests that produced the frozen format-6 scores. Use the original paid request and provider-response records when describing what Claude actually received; the historical configuration and preview are not current liquid-loading instructions.

The measured outcome is calibrated product yield. A productive mixture is a screening lead; this one-run design has no single-ligand reference or repeats, so it cannot by itself establish reproducibility or ligand cooperativity. Those comparisons belong to later follow-up experiments.
